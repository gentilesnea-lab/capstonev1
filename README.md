# Merge Conflict Activity

A small GitHub merge conflict simulation. Both branches edit the same greeting line in `message.txt`.

- Base branch: `main`
- Branch one: `feature/formal-greeting` changes the greeting to `Good morning, team!`
- Branch two: `feature/casual-greeting` changes the same line to `Hey everyone!`
- Resolution: keep both ideas as `Good morning, everyone!`

See `evidence/ACTIVITY_LOG.md` for the command transcript and `evidence/` for screenshots.
